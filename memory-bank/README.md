- [Постоянная установка на Arch](install.md): готовые локальный/rollback пакеты, backup и порядок замены старого DKMS source.

Цель: Maibenben P527 / Intel NUC X15 LAPAC71G: лимит заряда, подсветка клавиатуры и управление вентиляторами с возвратом BIOS. Поддержка исходных LAPQC71 должна сохраниться.

Текущий итог: изменения реализованы, проверены на устройстве и установлены через локальный Arch DKMS пакет `r81.ebab4af.p527.20261101`. Обычный modprobe загрузил проверенный A47 с постоянными keyboard/fan opt-in и debugregs=N. Пользователь подтвердил белую подсветку и обычную работу обоих вентиляторов; лимит80 и BIOSmanual0/mode2 проверены чтением. AC/DC RGB/brightness/OFF, смена профилей, оба PWM100%/~90%, BIOS handoff и два s2idle сценария прошли физические проверки.

Полный boot после установки отдельно не наблюдался; deep/hibernation и длительный ручной режим не проверены. По умолчанию вентиляторы остаются у BIOS. Резервная копия и rollback package находятся по пути в install.md. Новых аппаратных опытов для повторения уже подтверждённых результатов без причины не требуется.

Правила продолжения: отделять успешную сборку, чтение регистра и подтверждённый физический эффект. Не отмечать экспериментальную функцию рабочей без аппаратного теста. Для цвета спрашивать пользователя, называя ожидаемый цвет; для вентиляторов — ожидаемое ускорение/замедление. Записывать сюда результаты следующих сессий, включая ошибки и восстановление исходных настроек. Драйверы qc71 и TUXEDO не использовать одновременно как владельцев EC.

Продолжение для AUR: добавлена поддержка exact DMI LAPAC71H через общие с
LAPAC71G BIOS/EC/LED/PWM пути по запросу пользователя, подтвердившего одинаковые
адреса регистров. Аппаратных проверок LAPAC71H не было. Отдельный AUR рецепт
`qc71-laptop-lapac71-dkms-git` находится в `contrib/arch/aur`; прежний локальный
snapshot и rollback сохраняются. Пакетная подготовка не меняет установленный
модуль и системные options; результаты публикации и проверок — в progress.md.
