## Источники и регистры

`device-control.txt` и `addrs_to_check.txt` — уже имевшиеся у пользователя результаты анализа Intel NUC Software Studio / UniwillService 1.0.0.19. Их происхождение и полнота отдельно не проверены; список адресов не доказывает поддержку всех функций на данной плате. Пользовательское расширение debugfs.c сохранено.

| Назначение | EC |
|---|---|
| Лимит заряда | 0x07b9, bits6:0, 0 означает 100%; bit7 — статус |
| AppIsRunning / manual_control | 0x0741 bit0, влияет шире, чем только на вентиляторы |
| Legacy direct fan mode | 0x0751 bit6, другие биты — профиль firmware |
| Fan PWM | 0x1804/0x1809, raw 0..200; sysfs 0..255 |
| Fan RPM | 0x0464/0x046c, старший байт первым |
| CPU/GPU temp | 0x043e/0x044f |
| Keyboard capability | 0x0766 bit2, для новой реализации также exact DMI LAPAC71G |
| Keyboard AC RGB | 0x0769..0x076b, raw 0..50; физический красный подтверждён |
| Legacy keyboard level | 0x078c bits7:5; на P527 физическую яркость не меняет |
| Intel AC/DC controls | 0x07ea/0x07eb: level bits2:0, apply bit3, off bit4, rainbow bit5 |
| Intel DC RGB | 0x07ec..0x07ee, raw 0..50; синий/красный и сохранность AC подтверждены |
| Lightbar (другая подсветка) | 0x0748; RGB 0x0749..0x074b |

Однозонный RGB и legacy PWM совпадают с локальным tuxedo-drivers. RGB/яркость/OFF на AC и оба канала PWM на100%/~90% с возвратом BIOS подтверждены пользователем. Не переносить universal fan tables 0x0f00..0x0f5f и новые power profiles без отдельного подтверждения.

Пользователь подтвердил работу штатной Fn+F7: белый свет разных уровней, включая OFF→тусклый белый. Все отслеживаемые EC настройки при этом оставались неизменны. Цвет после активности подтверждён, яркость через078c — нет. Важна разница сохранённых настроек, физической Fn-яркости и активности клавиатуры.
